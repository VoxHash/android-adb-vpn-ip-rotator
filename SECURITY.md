# Security Policy

## Reporting a Vulnerability

Email **contact@voxhash.dev** with details and reproduction steps.

Do not open public issues for vulnerabilities that could expose devices, accounts, or network access.

We take security seriously and will respond promptly.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |

## Scope notes

- This tool drives a device you control via ADB. Protect USB debugging authorization.
- Never commit `servers.json` with private data, device serials, credentials, or real IP logs.
- Not affiliated with Windscribe Limited; use their apps under their own terms.
